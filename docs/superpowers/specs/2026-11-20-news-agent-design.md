# 뉴스·유튜브 TOP10 요약 에이전트: 설계서 (짧은 버전)

작성일: 2026-11-20 / 상태: 승인 대기

## 의도와 이유
- 유튜브로 뉴스를 볼 때 직접 찾아보는 시간을 아끼고 싶다.
- 더 큰 목적: "AI 에이전트가 자동으로 도는 구조"를 처음 끝까지 만들어 보는 경험. 이후 여행 계획, 맛집 블로그, 아버지 장부 등으로 확장하기 위한 연습이다.
- 번아웃 방지를 위해 2주 안에 끝낼 수 있는 크기로 한정한다.

## 목표
- 매일 오전 8시, 오후 7시에 뉴스 TOP10과 유튜브 TOP10을 요약해 카카오톡 "나에게 보내기"로 받는다.
- PC가 꺼져 있어도 동작한다.
- 월 비용은 AI 구독 1개 + API 소액 수준(월 10만 원 이내, 목표는 훨씬 아래).

## 추가된 요구 (2026-11-20, 사용자 요청)
- 뉴스 분야별 TOP3를 함께 요약한다. 분야는 6개: 정치·사회 / 경제·산업 / 국제 / IT·과학·인공지능 / 문화연예·스포츠 / 재난·환경·지역.
- 한 번에 받는 양: 뉴스 TOP10 + 분야별 TOP3(6개 x 3 = 18개) + 유튜브 TOP10.
- **결정됨 (사용자 선택: 링크 방식)**: 카카오 "나에게 보내기"의 텍스트 메시지는 글자 수 제한이 짧은 것으로 알고 있다(약 200자, 구현 시 현재 사양 확인). 그래서 카톡에는 핵심 한 줄 요약 + 링크만 보내고, 전체 내용(뉴스 TOP10, 분야별 TOP3, 유튜브 TOP10)은 GitHub Pages 웹페이지에서 본다. 페이지는 스크립트가 실행될 때마다 자동으로 갱신한다. 하루 2회분을 구분해 보여 준다.

## 비목표 / 안티목표
- 3개 AI 연동, 주식 분석, 앱/웹 서비스화, 남들에게 배포는 하지 않는다.
- 완벽한 요약 품질을 목표로 하지 않는다. "매일 자동으로 도착한다"가 성공 기준이다.
- 만드는 과정이 스트레스가 되면 범위를 줄인다. 기능을 늘리지 않는다.

## 검토한 접근
1. 노코드 도구(n8n, Make): 쉽지만 자유도와 학습량이 적다.
2. **AI 하나 + 간단한 파이썬 코드 (선택)**: 학습량이 많고 비용이 낮고, 공모전에서 "직접 만들었다"고 말할 수 있다.
3. 3개 AI 연동: 복잡하고 비용이 크다. 첫 도전으로는 과하다. 한계가 보이면 나중에 추가한다.

## 구조 (빌더의 판단 여지가 있는 부분은 표시함)
수집 → 요약 → 전송, 이 세 단계를 작은 스크립트로 만든다.
- 수집: 뉴스(RSS 또는 검색 API), 유튜브(공식 Data API의 인기 동영상 차트). *[내 판단, 구현 시 현재 API 사양 확인 필요]*
- 요약: Claude API 사용. *[중요] Claude Pro 구독과 API 요금은 별개이다. API 키를 따로 발급하고 소액을 충전해야 한다. 하루 2회 요약이면 비용은 매우 적을 것으로 예상하나 실제 사용량으로 확인한다.*
- 페이지 생성: 요약 결과로 간단한 HTML 페이지를 만들어 GitHub Pages에 올린다. *[내 판단] 공개 주소가 되므로 개인정보나 키는 넣지 않는다. 뉴스 요약은 공개되어도 무방하나, 기사 원문 전체를 복사하지 않고 제목, 짧은 요약, 원문 링크만 싣는다.*
- 전송: 카카오 "나에게 보내기" API로 한 줄 요약 + 페이지 링크를 보낸다. *[내 판단] 카카오 개발자 앱 등록과 토큰 발급이 필요하고, 토큰 갱신 처리가 필요하다.*
- 실행: GitHub Actions의 예약 실행(cron). *[내 판단] PC를 켜 두지 않아도 되고 무료 한도 내에서 가능하다. 대안은 Windows 작업 스케줄러(PC가 켜져 있어야 함).*

## 제약
- 파이썬 경험은 없고 HTML 바이브코딩 경험만 있다. 코드는 Claude가 같이 작성하고 설명한다.
- 키와 토큰은 코드에 직접 넣지 않고 비밀 저장소(GitHub Secrets 등)에 둔다.
- 유튜브/뉴스 데이터는 공식 API나 RSS만 쓰고, 무단 크롤링은 하지 않는다.

## 빌더에게 남기는 것

- TOP10 선정 기준(카테고리 필터 여부)
- 실패했을 때의 알림 방식
